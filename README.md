# Video Person Frame Extractor

浏览器本地运行的通用视频人物关键帧提取器。

## v0.2 智能扫描
v0.2 不再固定每 0.5 秒调用一次人物模型，而是先做轻量场景变化分析：
1. 按“场景扫描步长”快速读取画面。
2. 计算低分辨率场景差异。
3. 只有镜头明显变化，或达到兜底检测间隔时，才调用 COCO-SSD 的 `person` 检测。
4. 同一镜头内最多保留 1～3 张质量更高的关键帧。
5. 同镜头相似帧使用人物区域 dHash 去重。

这让长视频的人物模型调用次数显著低于场景采样次数，同时保留跨镜头的人物画面。

## 功能
- 本地视频文件或允许 CORS 的视频 URL
- TensorFlow.js COCO-SSD 检测 `person`
- 场景变化预筛 + 周期兜底人物检测
- 快速 / 平衡 / 精细三档预设
- 每镜头最佳帧筛选
- 人物区域相似去重
- 结合置信度、人物面积、清晰度和场景变化的质量评分
- 原始分辨率 JPEG 输出
- 导出 `people.json`、`contact-sheet.jpg`、完整 ZIP
- 显示场景采样次数、人物模型调用次数、识别镜头数和保留帧数

## 使用
打开 GitHub Pages 页面，优先选择本地视频后点击“开始智能识别”。

网络 URL 会受到视频来源站点的 CORS、鉴权和容器格式限制；不兼容时请先用对应下载工具得到 MP4，再作为本地文件处理。

## 隐私
视频字节不上传到本项目服务器。处理发生在当前浏览器中。模型和前端依赖通过 CDN 加载。

## 技术
TensorFlow.js + COCO-SSD + Canvas API + JSZip。

当前版本只判断画面中是否存在人物并提取关键帧，不做人脸识别，不推断人物身份。
